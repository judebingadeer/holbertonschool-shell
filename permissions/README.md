# Shell Permissions

0-iam_betty: Switch to user betty.

1-who_am_i: Prints the effective username.

1-who_am_i: Prints the effective username.

2-groups: Prints all groups the current user belongs to.

3-new_owner: Changes the owner of hello to betty.

4-empty: Creates an empty file named hello.

5-execute: Adds execute permission to the owner of hello.

6-multiple_permissions: Adds execute permission to owner and group, and read permission to others.

7-everybody: Adds execute permission to all users.

8-James_Bond: Sets permissions to 007 for hello.

9-John_Doe: Sets permissions of hello to 753.

9-John_Doe: Sets permissions of hello to 753.

10-mirror_permissions: Copies permissions from olleh to hello.
